Accessibility Checklist

General accessibility checks for portfolio and web content.

Structure

  • Use a logical heading hierarchy.
  • Use semantic HTML where appropriate.
  • Keep page structure clear and predictable.

Content

  • Use descriptive link text.
  • Keep instructions clear and concise.
  • Avoid relying on color alone to communicate meaning.

Visual Design

  • Check text and background contrast.
  • Maintain readable text sizes.
  • Allow sufficient spacing between interactive elements.

Interaction

  • Ensure interactive controls have clear labels.
  • Check keyboard accessibility.
  • Provide visible focus states.
