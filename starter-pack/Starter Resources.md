# Starter Resources

Basic resources and reusable starting points for building a personal portfolio website.

## Included

- `accessibility-checklist.html` — General accessibility checks for web pages.
- `design-system-notes.html` — Basic notes on typography, spacing, color, components, and responsive design.
- `portfolio-template.html` — Simple starting structure for a personal portfolio page.
- `initial-css.css` — Lightweight starter stylesheet for common layouts and components.

## Notes

These files are intended as general-purpose starting points and can be adapted, expanded, or replaced as the site develops.

The examples are intentionally simple so they can be reused as a foundation for different personal projects.
